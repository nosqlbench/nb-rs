# SRD History — archived design records

Superseded design memos, implementation plans for **shipped** work, and the
polydat-internal mechanism notes that predate polydat-as-a-crate (their substrate
design now lives authoritatively in `polydat/docs/design/`). Kept for the *why* — not
authoritative.

The canonical reference is the numbered SRD set in the parent directory: start at
[../00_index.md](../00_index.md) or [../../SYSREF.md](../../SYSREF.md). Living (non-archived)
design rationale is in [../notes/](../notes).
